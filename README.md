# Nordis Terminal

Учебный демонстрационный макет кабинета брокера в тёмной теме. Вымышленный бренд, все данные условны,
ордера на биржу не отправляются.

## Состав
- `public/index.html` — сайт и личный кабинет (обзор, терминал, платежи, вывод, инструменты, помощник, профиль)
- `public/bot.html` — кабинет торгового ИИ-бота: вход, подключение по ключу API, расчёт прогноза, сессия
- `public/admin.html` — админка: кошельки, сценарии, заявки, комиссии, HTML-редактор всех блоков
- `server.js` — Express API: регистрация, сессии, кошельки, конфигурация сайта, бот
- `db.js` — схема PostgreSQL

## Переменные окружения
- `POSTGRESQL_HOST`, `POSTGRESQL_USER`, `POSTGRESQL_PASSWORD`, `POSTGRESQL_DBNAME`, `POSTGRESQL_PORT`
- `ADMIN_KEY` — ключ входа в админку
- `PORT` — порт приложения (по умолчанию 3000)

Настройки контента хранятся в отдельной таблице `site_config_nordis`, поэтому не пересекаются
с другими проектами в той же базе.
